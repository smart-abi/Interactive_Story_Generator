# Interactive_Story_Generator

This project is an **Interactive Story Generator** built during my internship. 
It allows users to create dynamic stories by taking inputs and generating customized story outputs.

## Features
- Generate interactive stories based on user input
- Randomized story elements for unique experiences
- Text-based project, perfect for learning Python programming and logic

## Technologies Used
- Python
- Google Colab (optional)
- Standard Python libraries

## How to Run
1. Download the project files.
2. Open the main code file (`Interactive_story_generator.py` or your main file).
3. Run in Python IDE (or Google Colab if notebook).
4. Enter inputs as prompted to generate interactive stories.
